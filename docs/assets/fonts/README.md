# Embedded paper fonts

Libertinus Serif Regular, Bold and Italic are bundled to make the paper's typography consistent across PDF viewers and operating systems. The fonts are distributed under the SIL Open Font License in [OFL.txt](OFL.txt).

Source: https://github.com/google/fonts/tree/main/ofl/libertinusserif

The renderer embeds subsets of these fonts. It does not rely on a viewer substituting Times or on fonts installed on the author's computer.
