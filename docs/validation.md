# Release verification

## Verified scope

- All 187 desk tasks passed the supplied strict validator: the reference solution passes, the untouched workspace fails, and repeated generation is deterministic under the validation environment. Native spreadsheet recalculation used LibreOffice in Docker.
- All 20 build task packs passed seed regeneration, checklist structure, referenced-file, and expected-number validation. This validates the task packages, **not any agent-built applications**.
- Unit checks cover inventory completeness, ledger arithmetic, rejection of an incomplete arm, a real subprocess runner smoke, refusal to overwrite an attempt, and a reference/empty grading pair.
- The Docker agent image built from the release recipe, reported Codex CLI 0.154.0, and passed the five unit/smoke tests inside the clean container. No model login or paid model call was needed for these checks.
- The ledger contains exactly 2,244 distinct attempts across four full 187-by-three arms. Original result hashes are retained; raw artifacts are not included.

## Fixture regeneration notices

The strict validator reported 28 tasks whose supplied files differ from regenerated bytes. It treats these as notices rather than failures when repeated regeneration agrees. No supplied fixture or reference was replaced to conceal this difference. The published fixture bytes, recorded in the release manifest, define the runnable release. Regenerated variants must be separately identified; byte drift is not assumed to be merely metadata or semantically harmless.

The affected tasks are bank-statement-pdf, business-cards-scanned, card-statements-pdf, catering-quotes-table, contract-key-terms, cv-batch-extraction, grant-award-letters, inspection-findings, insurance-certificates, lease-abstracts, monthly-report, monthly-report-v9, packing-slips-vs-po, pay-stubs-extraction, permission-forms-scanned, property-tax-bills, purchase-orders-pdf, quote-comparison, receipts-scanned, shipment-manifests, superbill-codes, supplier-invoices-to-csv, tenant-statements, timesheets-scanned, utility-bills-extraction, vendor-price-sheets, vendor-tax-forms, and venue-invoices.

## What was not verified by packaging

This release did not run a new paid model campaign, rescore the original 2,244 output workspaces, establish independent human agreement with the checks, or certify the build acceptance results. Original campaign records lack immutable per-attempt scorer/image receipts. A portable clean installation is not a reconstruction of undistributed historical runtime binaries or authenticated tool/skill inventories. These limitations are stated in the paper and results, not hidden in the work log.
