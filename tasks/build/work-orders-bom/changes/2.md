# Change request 2

When a part drops below its reorder point, raise a purchase request for it automatically, for enough to
bring it back up to twice the reorder point, and never a second one while the first is still open. When we
receive the parts, put them into stock and close the request.

---

Rerun the full checklist, then check these three additional items. Create as admin: component QA-BOLT with
50 on hand, reorder point 40, unit cost 0.10; finished good QA-KIT whose BOM is QA-BOLT x 4. Delete them,
their work orders, and their purchase requests after item 32.

30. [Automation] Stock falling below the reorder point raises one purchase request for twice the reorder point minus what is on hand.
    How to check: As admin, create a work order for QA-KIT, quantity 5, on Line 1 - Tables, and start it (QA-BOLT goes from 50 to 30). Do nothing else; reload the purchase requests. Pass only if exactly one open purchase request exists for QA-BOLT with quantity **50** (2 x 40 - 30). Fail if none exists, the quantity differs, or it needed a manual step.

31. [Rule] A part never has two open purchase requests.
    How to check: Create and start a second QA-KIT work order, quantity 2 (QA-BOLT goes from 30 to 22). Reload. Pass only if QA-BOLT still has exactly one open purchase request (its quantity may stay 50 or become 58). Fail if a second open request appears.

32. [Automation] Receiving a purchase request adds its quantity to stock and closes it.
    How to check: Mark QA-BOLT's purchase request received in full. Reload QA-BOLT and the request. Pass only if on hand is 22 plus the received quantity (72 or 80) and the request is closed or received, not open. Fail if stock is unchanged or the request stays open.
