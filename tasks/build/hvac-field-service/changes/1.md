# Change request 1

Add a warranty flag on jobs with an expiry date, and a report of jobs still under warranty.
If a job is flagged as warranty it needs the expiry date filled in.

---

Rerun the full checklist, then check these three additional items.

32. [Exact] Every job has a warranty flag and a warranty expiry date, and both save.
    How to check: As admin, open an existing job, turn the warranty flag on, set expiry to 2027-06-30, save, reload. Pass only if the flag is still on and the date still reads 2027-06-30. Fail if either field is absent or does not persist.

33. [Rule] A job flagged as warranty cannot be saved without an expiry date.
    How to check: As admin, on a job turn the warranty flag on, leave expiry blank, save. Pass only if the save is rejected with a visible message and, after reloading, the job is not flagged. Fail if it saves with a blank expiry.

34. [Exact] The under-warranty report lists exactly the jobs whose warranty flag is on and whose expiry date is today or later.
    How to check: As admin, create three jobs for any customer: W1 flagged with expiry 2027-06-30, W2 flagged with expiry 2025-01-31, W3 not flagged. Open the report. Pass only if W1 appears, neither W2 nor W3 appears, and each row shows at least the customer and the expiry date. Fail if the report is absent or its contents differ.
