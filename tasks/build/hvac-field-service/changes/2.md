# Change request 2

Techs need to log parts used from their phone while they're on site: pick the part, put in the
quantity, done. They shouldn't see our prices or costs, and they shouldn't see any customers
other than the ones on their own jobs.

---

Rerun the full checklist, then check these three additional items. Use technician login T and
job A from item 14; if that login no longer exists, recreate both as admin.

35. [Delivery] From a phone-sized screen, a technician can add a part line to an assigned job.
    How to check: As T, on a phone or in desktop browser device emulation at 390 x 844, open job A, add CAP-45-5-440 with quantity 1, save. Pass only if every control needed (opening the job, picking the part, entering the quantity, saving) is reachable without scrolling sideways, and after reloading as admin the line appears on job A. Fail if any step requires horizontal scrolling or the line is missing for admin.

36. [Permission] The technician login is never shown a unit cost or sell price, on screen or in data responses.
    How to check: As T, open job A, the part picker, the parts list if one is reachable, and the invoice if one is reachable; then in devtools > Network inspect the responses that loaded the job, its part lines, and the part picker. Pass only if no cost or price value appears anywhere on screen and no populated cost or price field (such as unit_cost, sell_price, price, cost) appears in any response. Fail on a single occurrence. If the app is entirely server-rendered with no data responses, only the on-screen check applies.

37. [Permission] The technician login sees no customers beyond those on its own jobs.
    How to check: As T, open any customers screen or search that exists: only the customers of T's assigned jobs appear. Paste the URL of a customer with no job assigned to T (for example the one used in item 12): the page shows an error or access-denied without that customer's name, phone, email, or address. Repeat the item-13 request replay using T's session. Pass only if all three hold.
