# Northgate Valve Co. handbook

Company policies for approving requisitions. Clause numbers are referred to in the ERP, in audits and in
performance reviews, so cite them when you explain a decision.

- [Approving requisitions](approvals.md) (APR)

Every requisition is assigned first to the requester's department head. An approver decides each requisition
assigned to them: approve it, forward it to another approver, return it to the requester to change and
resubmit, or reject it. A forwarded requisition waits for the new approver; nobody else can decide it.
