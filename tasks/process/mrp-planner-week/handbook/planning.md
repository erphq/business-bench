# Material planning (PLN)

**PLN-1.1** Before running MRP, bring the item records up to date with any planning data a vendor has confirmed in
writing since the last run (for example a new lead time). Changes arrive in the planning inbox.

**PLN-1.2** Run MRP every Monday with an eight-week horizon and a five-workday firm fence.

**PLN-2.1** Release every firm planned order from that run (release date on or before the firm fence), with the
quantity and need date MRP suggests. Leave planned orders outside the fence for a later run.

**PLN-2.2** A planned purchase order that is late (its release date has passed) is released like any other firm
order, and the same day you ask the vendor to expedite it to MRP's need date.

**PLN-3.1** Work every action message from the run the same day: for expedite, ask the vendor to expedite the
purchase order line to MRP's need date; for defer, ask the vendor to defer it to MRP's need date; for cancel, ask
the vendor to cancel the line. Do not ask again about a line when you already have a request of the same kind open
or answered for it.

**PLN-3.2** Do not change sales orders, bills of materials or forecasts; they belong to sales and engineering.
